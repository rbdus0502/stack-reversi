# 배틀 리버시 (가제)

리버시처럼 끼워서 두지만, 끼운 기물은 바로 뒤집히지 않고 **대미지**를 받는 웹 보드게임입니다.

## 규칙 요약

- **놓기**: 상대 말을 끼울 수 있는 빈칸에 유닛을 골라 놓습니다.
- **대미지** = 둔 기물 공격력 + 반대쪽 끝 내 기물(**받침**) 공격력. 줄마다 받침이 달라 대미지도 다를 수 있어요.
- **기물**은 HP가 있어 버티다가, HP가 0이 되면 깨져서 상대 색 **토큰**이 됩니다. 토큰은 맞으면 무조건 뒤집혀요.
- **유닛**: 병사(HP1·공1·무제한), 방패병(HP3·공0·3개), 창병(HP1·공2·3개), 포탑(HP2·공0·2개, 내가 행동할 때마다 상하좌우 적에게 1)
- **이동권 3개**: 내 기물을 1칸 옮겨 공격(턴 소모, 공격 +1).
- **종료**: 두 사람이 연속으로 패스하면 끝. 말 수 → 같으면 HP 합으로 승패.

전체 명세는 [docs/RULES.md](docs/RULES.md), 기획 의도는 [docs/DESIGN.md](docs/DESIGN.md)에 있습니다.

## 화면과 편의 기능

- 마우스를 올리면(휴대폰은 첫 탭) 미리보기: 줄마다 대미지 숫자, 받침 강조, 깨질 기물, 뒤집힐 토큰, 포탑 발사 칸을 서로 다르게 표시. 두 번째 탭/클릭에 확정
- 내 기물을 누르면 이동 가능한 칸이 화살표로 표시
- 하단 유닛 선택 바(남은 수량, 숫자키 1~4로도 선택)
- 대미지 숫자가 튀어오르는 연출, 기물이 깨지는 연출, 토큰 회전
- 무르기 / 다시 (Ctrl+Z / Ctrl+Y), 기보 클릭으로 복기, 새로고침해도 이어하기
- AI 대전(쉬움/보통/어려움, 흑·백 선택) 및 한 화면 2인 대전
- 4단계 튜토리얼, 효과음, 다크 모드, 휴대폰 세로 화면 대응

이전 규칙(스택 리버시, v0.1)은 `v0.1` 태그에 남아 있습니다.

## 개발

```bash
npm install
npm run dev        # 개발 서버
npm run test       # 규칙 테스트 (RULES.md 9절 T1~T19, 미리보기 일치 테스트)
npm run build      # 배포용 빌드
npm run selfplay -- --games 500 --depth 3   # AI 셀프플레이 밸런스 측정
```

셀프플레이는 `--tickets`, `--charge`, `--unit guard.maxHp=4` 처럼 규칙 수치를 바꿔 비교할 수 있습니다.

`main`에 푸시하면 GitHub Actions가 테스트 → 빌드 → GitHub Pages 배포를 자동으로 합니다.
