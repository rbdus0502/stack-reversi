# 스택 리버시

리버시에 **겹치기**를 더한 웹 보드게임입니다. 내 돌 위에 돌을 쌓아 방패를 만들고, 한정된 토큰을 결정적인 순간에 쓰세요.

## 규칙 요약

- **놓기**: 일반 리버시처럼 상대 돌을 끼우면 색이 바뀝니다.
- **겹치기**: 내 더미 위에 한 층을 더 쌓습니다. 토큰 1개 소모(1인당 5개), 최대 3층, 끼우기가 성립해야 합니다.
- **방패**: 2층 이상인 상대 더미는 끼워져도 색이 바뀌지 않고 한 층만 깎입니다.
- **종료**: 두 사람이 연속으로 패스하면 끝. 칸 수가 많은 쪽이 이기고, 같으면 층 합으로 가립니다.

전체 명세는 [docs/RULES.md](docs/RULES.md)에 있습니다.

## 편의 기능

- 마우스를 올리면(휴대폰은 한 번 탭) 색이 바뀔 칸과 한 층 깎일 칸을 서로 다르게 미리보기, 한 번 더 탭하면 확정
- 놓기 가능 칸(점)과 겹치기 가능 칸(주황 +)을 구분 표시, 표시 끄기 가능
- 무르기 / 다시 (Ctrl+Z / Ctrl+Y), AI 대전에서는 내 차례까지 한 번에 되돌림
- 기보: 클릭하면 그 시점으로 이동해 복기, 그 지점부터 다시 둘 수도 있음
- 새로고침해도 진행 중인 판이 이어짐
- AI 대전(쉬움/보통/어려움, 흑·백 선택) 및 한 화면 2인 대전
- 3단계 튜토리얼, 효과음(끄기 가능), 다크 모드, 휴대폰 세로 화면 대응

## 개발

```bash
npm install
npm run dev        # 개발 서버
npm run test       # 규칙 테스트 (RULES.md 9절 T1~T10)
npm run build      # 배포용 빌드
npm run selfplay -- --games 500 --depth 3   # AI 셀프플레이 밸런스 측정
```

`main`에 푸시하면 GitHub Actions가 테스트 → 빌드 → GitHub Pages 배포를 자동으로 합니다.
