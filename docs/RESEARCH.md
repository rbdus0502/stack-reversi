# 1차 조사 — 유사 게임·시스템 (2026-10-18)

## 결론
**차별화 보강 후 진행.** "오셀로 + 체력·대미지"는 이미 있는 장르지만, **판 위 기물 하나하나에 HP가 있어 끼워도 바로 뒤집히지 않는 방식**은 찾지 못했다.

## 우리가 다른 점
1. HP가 플레이어가 아니라 **판 위 기물**에 있다 → 위치 싸움이 깊어짐.
2. 무작위·가챠 없음. 순수 전략.
3. 모든 기물이 병사면 일반 리버시와 같다 → 배우기 쉬움.
4. 웹 링크로 즉시 플레이, 짧은 한 판.

## 주의
- "오셀로(Othello)"는 등록상표다. 게임 이름·설명에 쓰지 않는다. "리버시"는 일반 명칭.
