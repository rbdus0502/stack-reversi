# 게임 규칙 명세 v0.1 (가제: 스택 리버시)

이 문서가 규칙의 단일 기준이다. 코드와 이 문서가 다르면 이 문서를 따른다.
규칙을 바꾸면 이 문서와 `src/engine/config.ts`, 테스트를 함께 바꾼다.

## 1. 용어

- **칸(cell)**: 비어 있거나, 한 개의 **더미(stack)** 를 가진다.
- **더미**: `{ owner: 'B' | 'W', height: 1..MAX_HEIGHT }`. 소유자는 맨 위 돌의 색이다.
- **토큰(stack token)**: 겹치기를 할 때 1개씩 쓰는 자원.

## 2. 설정값 (모두 config로 분리, 기본값)

| 키 | 기본값 | 설명 |
| --- | --- | --- |
| `BOARD_SIZE` | 8 | 판 크기 |
| `MAX_HEIGHT` | 3 | 더미 최대 층수 |
| `STACK_TOKENS` | 5 | 1인당 겹치기 토큰 |
| `STACK_MUST_FLIP` | true | 겹치기도 반드시 1개 이상 뒤집어야 하는가 |

## 3. 좌표

열은 a–h(왼쪽→오른쪽), 행은 1–8(위→아래). 내부 표현은 `row = 행-1`, `col = 열-'a'`.

## 4. 시작

- d4 = 백(1층), e5 = 백(1층), e4 = 흑(1층), d5 = 흑(1층).
- 흑이 먼저 둔다. 토큰은 양쪽 모두 `STACK_TOKENS`개.

## 5. 수의 종류

내 차례에는 다음 중 하나를 반드시 한다(가능한 수가 있으면 자발적 패스 불가).

### 5.1 놓기 (place)
- 빈칸에 내 색 1층 더미를 놓는다.
- 8방향 중 한 방향 이상에서 **상대 더미가 1개 이상 연속되고 그 끝에 내 더미가 있어야** 한다(일반 리버시와 같은 끼우기 판정).

### 5.2 겹치기 (stack)
- 조건: 그 칸이 **내 더미**이고, `height < MAX_HEIGHT`, 내 토큰 ≥ 1.
- `STACK_MUST_FLIP`이 true면, 그 칸을 기준으로 5.1과 같은 끼우기 판정이 1방향 이상 성립해야 한다.
- 결과: 그 칸 height + 1, 토큰 − 1, 끼운 돌 처리(6절).
- 상대 더미 위에는 겹칠 수 없다.

## 6. 끼운 돌 처리 (방패 규칙)

끼우기가 성립한 모든 방향의 상대 더미 각각에 대해:
- `height == 1` → owner를 내 색으로 바꾼다(height는 1 유지).
- `height >= 2` → owner는 그대로, height − 1.

판정은 **수를 두기 전 상태로 한 번에** 한다. 처리 도중 바뀐 색으로 다시 판정하지 않는다(연쇄 없음).
끼우기 판정에서 더미는 높이와 상관없이 "그 색의 돌 1개"로 취급한다.

## 7. 패스와 종료

- 놓기와 겹치기가 모두 불가능하면 패스.
- 두 사람이 **연속으로** 패스하면 게임 종료.
- 판이 가득 차도 겹치기가 가능하면 게임은 계속된다.

## 8. 점수와 승패

1. 내 색 칸의 수가 많은 쪽이 승리.
2. 같으면 내 색 칸들의 height 합이 큰 쪽이 승리.
3. 그래도 같으면 무승부.

## 9. 필수 테스트 케이스

아래는 별도 참조 구현으로 결과를 검증한 케이스다. 엔진 테스트에 그대로 옮긴다.
표기: `B1` = 흑 1층, `W2` = 백 2층, `·` = 빈칸. 특별히 적지 않은 칸은 빈칸, 흑 차례, 흑 토큰 5개.

| ID | 상황 | 행동 | 기대 결과 |
| --- | --- | --- | --- |
| T1 | 시작 배치 | 흑 합법수 계산 | 놓기: c4, d3, e6, f5. 겹치기 없음 |
| T2 | a1=B1, b1=W1, c1=B1 | 흑 합법수 계산 | 겹치기: a1, c1 (둘 다 b1을 끼움) |
| T2b | T2 배치 | 흑 c1 겹치기 | a1=B1, b1=B1, c1=B2, 흑 토큰 4 |
| T3 | a1=B1, b1=W2 | 흑 c1 놓기 | b1=W1(색 유지, 한 층 감소), c1=B1 |
| T4 | a1=B1, b1=W1, c1=W2 | 흑 d1 놓기 | b1=B1, c1=W1, d1=B1 |
| T5 | a1=B1, b1=W2, c1=W1 | 흑 d1 놓기 | b1=W1, c1=B1, d1=B1 (판정은 둔 직후 한 번만) |
| T6 | a1=B1, b1=W1, c1=W1, d1=B3 | 흑 합법수 계산 | a1 겹치기만 가능. d1은 최대 층이라 불가 |
| T7 | T2 배치, 흑 토큰 0 | 흑 합법수 계산 | 합법수 없음 → 패스 |
| T8 | 상대 더미 위 | 흑이 W 더미 칸에 겹치기 시도 | 불법 수로 거부 |
| T9 | 양쪽 모두 합법수 없음 | 연속 패스 2회 | 게임 종료, 8절로 승패 계산 |
| T10 | 칸 수 동점, 흑 height 합이 더 큼 | 종료 판정 | 흑 승 |

## 10. 밸런스 메모 (기획 단계 시뮬레이션)

무작위 봇과 탐욕 봇(가장 많이 뒤집는 수)으로 수백~수천 판을 돌린 결과다.
- 겹치기 무제한 + 돌 개수 제한: 마지막 수를 두는 쪽이 65~75% 승리 → 탈락.
- **토큰 5개 + 연속 패스 종료(현재 규칙)**: 탐욕 봇 기준 흑 48% / 백 48% / 무 4%.
- 봇이 약하므로, 미니맥스 AI 셀프플레이로 반드시 재검증한다(로드맵 2단계).
- **미니맥스 셀프플레이 재검증 (2026-10-18)**: 깊이 3 AI끼리 500판(처음 4수 무작위), 토큰 5 / 최대 3층.
  흑 50.4% / 백 48.8% / 무 0.8%, 흑-백 차이 1.6%p(기준 10%p 이내 통과). 평균 73.2수, 판당 겹치기 10.0회(양쪽 모두 토큰을 다 씀).
